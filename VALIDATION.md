## Исправление сохранения профиля macOS 4.1.11 — 8 октября 2026

На компьютере пользователя подтверждена причина сообщения `permission denied`: целевой JSON принадлежал root с правами 0644, а папка configs принадлежала пользователю и была доступна для записи. Этот файл заменён идентичной копией от имени пользователя; SHA-256 содержимого до и после совпал. Подписки и системное подключение при восстановлении не изменялись.

В macOS проверка конфигурации теперь сохраняет результат в уникальной временной папке рядом с целевым файлом и после успешного ответа ядра атомарно заменяет прежний файл. Проверка и замена не требуют повышения привилегий. Ошибка проверки или отсутствие результата сохраняет предыдущую конфигурацию; временная папка удаляется. Android использует прежний путь сохранения, готовый APK остаётся 4.1.10.

Пять новых тестов проверяют замену файла только для чтения, сохранение прежнего файла при отказе, исключении и отсутствии выходного файла, а также независимые временные пути 20 параллельных обновлений. Полный набор — 193 теста, все пройдены, включая публичные подписки с 35 516 и 66 822 серверами. Анализ трёх изменённых модулей/тестов без замечаний.

Дополнительный независимый экземпляр комплектного нативного ядра на случайном localhost-порту воспроизвёл исходный `permission denied` при прямой записи файла 0444. Тот же импорт 35 516 серверов через временный файл и замену прошёл успешно. Некорректная конфигурация отклонена, сохранённый файл остался на месте. Реальные профили пользователя в этом стенде не использовались.

Release macOS 4.1.11 (40111) собран. Проверены глубокая подпись приложения, отдельная подпись сетевого помощника и целостность ZIP. Приложение после установки этой версии через пользовательский интерфейс пока не проверялось.

## Проверки и оптимизация 4.1.10 — 8 октября 2026

- Русский интерфейс независимо от языка устройства и ранее сохранённого языка. Из настроек удалён выбор языка; MaterialApp поддерживает только ru. Добавлен тест миграции сохранённого en и невозможности переключения обратно. Меню macOS переведено; CFBundleDevelopmentRegion/CFBundleLocalizations — ru. Android Application использует русский контекст ресурсов. Системные окна, принадлежащие ОС, зависят от её языка.
- В предварительной проверке только `https://www.youtube.com/generate_204`; проверка миниатюры исключена. Добавлен тест единственного целевого URL. HTTP 204 подтверждает только предварительную доступность; успех воспроизведения по-прежнему требует 5 секунд и 10 кадров.
- Закреплённый Hiddify Core v4.1.0 пересобран для macOS arm64 и Android arm64-v8a/armeabi-v7a/x86_64. В monitoring defaultWorkerCount увеличен с 10 до 20, верхний предел — 20. URLs ограничены YouTube, исключены дополнительные IP-запросы внутри проверки задержки. Настройки приложения также передают единственный тестовый URL, включая случаи, когда подписка переопределяла его. Патч и команды воспроизведения сборки — в native-patches/README.md.
- Локальный стенд с 60 SOCKS-конфигурациями подтвердил максимум 20 одновременно ожидающих ответа запросов и единственный адрес назначения www.youtube.com:443. Все соединения обслуживались и отклонялись локально; подключение к реальным серверам пользователя не менялось. Счётчик завершает запрос при отправке ответа, поэтому не включает TCP-соединения, ожидающие обработки FIN. Проверена передача HTTP через локальный mixed-прокси пересобранного ядра.
- Оптимизация: Android-ядро собрано с обычной оптимизацией Go, без upstream `-gcflags 'all=-N -l'`, отключавшего оптимизации и встраивание. macOS-библиотека собрана только для целевой архитектуры arm64. Распакованное приложение macOS уменьшилось с 196,5 до 103,9 МБ. Дополнительные IP-пробы больше не расходуют время проверок и не заменяют задержку YouTube задержкой ответа другого сайта. Ускорение зависит от протокола и сети; время запуска/воспроизведения на физических устройствах не измерялось.
- Все 89 Flutter-тестов прошли, включая обе реальные подписки с 35 516 и 66 822 серверами. Пересобранное ядро отдельно успешно преобразовало оба снимка; обработка событий продолжалась во время RPC. Статический анализ изменённых Dart-модулей и тестов — без замечаний. Android-ядро пока не проверено на физическом устройстве.
- Готовые release-сборки 4.1.10 (40110). macOS codesign --verify --deep --strict успешен. Android APK v2-подпись проверена, сертификат совпадает с предыдущими версиями. Секции .text и .rodata всех трёх библиотек APK совпадают с пересобранным AAR; остальные различия обусловлены удалением служебных секций Gradle. Проверены архивы. Исходный Gradle distributionUrl восстановлен перед упаковкой исходников.

## Большие подписки 4.1.9 — 8 октября 2026

Разбор заголовков и base64, чтение/запись содержимого подписки, декодирование protobuf OutboundsInfo и сортировка вынесены в Dart isolate. Клиент получает необработанные байты через тот же gRPC-метод, сохраняя настройки канала и авторизации. Обработка обновлений ограничена одной текущей задачей и одним последним ожидающим снимком; промежуточные устаревшие снимки заменяются. Обновления списка ограничены интервалом 250 мс. Сортировка не изменяет исходный снимок и корректно сравнивает одинаковые/неизмеренные задержки. При выборе сервера сохраняется последний снимок задержек.

Главная страница больше не подписывается на полный отсортированный список. Для проверки пинга получает первый снимок группы по нажатию, с таймаутом 10 секунд. Разворачивание вложенных URL остаётся ограничено четырьмя загрузками; обработка обычных строк периодически уступает управление интерфейсу. Временные файлы вложенных загрузок удаляются, отмена не записывает неполную подписку. При офлайн-обновлении временный файл сохраняется до завершения фонового разбора и проверки ядром.

Пройдены 84 Flutter-теста: существующие проверки профилей, интерфейса и YouTube плюс семь проверок производительности/потоков. Проверены реальный localhost gRPC-канал с 10 000 серверами, декодирование снимков, сортировка 50 000 серверов, импорт 50 000 ссылок с base64-заголовком, сохранение только последнего из 10 000 ожидающих обновлений, отмена и восстановление после ошибки обработчика. В тестовом запуске сортировка 50 000 элементов заняла 125 мс, периодический обработчик основного isolate сработал 80 раз; разбор 50 000 ссылок занял 37 мс, обработчик сработал 33 раза. Это измерения на данном Mac в тестовом окружении, не гарантия времени на телефоне и не проверка реального соединения со всеми серверами. Статический анализ изменённых модулей и тестов — без замечаний.

Подтверждение YouTube по реальным видеокадрам и срок действия macOS-разрешения до полного выхода сохранены. Новая сборка не запускалась с реальной большой подпиской пользователя на macOS или физическом Android-устройстве.

Release-сборки macOS и Android 4.1.9 (40109) завершены. macOS codesign --verify --deep --strict и отдельная подпись помощника проверены. Android apksigner verify проверен; сертификат совпадает с версией 4.1.8. Android package ID dev.proxyyou.client, минимальная версия API 24. ## Исправление срока разрешения macOS 4.1.6

Пользователь подтвердил сбой версии 4.1.5 спустя примерно 30 секунд после запуска. Сохранение AuthorizationRef не продлевает срок учётных данных. Правило `authenticate-admin-nonshared` имеет timeout 30 в [исходниках Apple Security](https://github.com/apple-oss-distributions/Security/blob/main/OSX/authd/authorization.plist).

Вместо повторной проверки истёкшего права используется временный привилегированный дочерний процесс ProxyYouProxyHelper. Один запрос выполняется при его запуске перед Flutter; после запуска процесс управляет только словарями системного прокси через SystemConfiguration. Команды принимаются по приватному stdin/stdout-каналу, без сетевого сокета, произвольного выполнения команд или установки launch daemon. Помощник восстанавливает настройки и завершается при finish либо закрытии канала после выхода/сбоя приложения. Прежние настройки также сохраняются приложением для восстановления при следующем запуске. Ошибки commit/apply возвращают данные для восстановления. При восстановлении настройки другого приложения не перезаписываются.

Для локальной ad hoc-сборки используется устаревший AuthorizationExecuteWithPrivileges через C-обёртку. API остаётся доступным в установленном macOS SDK, но Apple рекомендует ServiceManagement для распространяемого продукта. Xcode сообщает предупреждение deprecated. Переход на подписанный ServiceManagement-helper и нотарификация не выполнены в этой локальной сборке.

Проверены Swift-тесты изменения портов и восстановления, сохранение внешних изменений, отказ неизвестным командам и 20 переподключений.
