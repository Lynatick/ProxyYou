# Проверка ProxyYou 4.1.21

Дата: 15 октября 2026. Flutter 3.47.7 stable, Dart 3.13.5.

Публикуются только Android APK и Windows Setup EXE. Подготовленные и проверенные
macOS Silicon/Intel пакеты остаются локальными: пользователь приостановил их
публикацию. Сайт предлагает для Mac предыдущий опубликованный выпуск.
Локальные Mac ZIP собраны до последней правки запуска; перед возобновлением
публикации для Mac потребуется пересборка.

## Автоматические проверки

- macOS: статический анализ без замечаний, 242 Flutter-тестов прошли,
  включая две реальные подписки пользователя (33 728 и 65 736 конфигураций).
  Проверки повторены на отдельном SDK с обходом AOT.
- Windows 11 ARM64 с x64 SDK под эмуляцией: чистая генерация,
  статический анализ, 236 тестов прошли; 6 пропущены по платформе
  (четыре теста macOS tray, два теста прав POSIX).
- JavaScript: 18 тестов проверки доказательства воспроизведения и выбора
  пакетов на сайте загрузки прошли.
- Нативное ядро Windows проверено из финального каталога сборки:
  группы select/balance/lowest сохраняют `interrupt_exist_connections=false`;
  предел проверки — 20 работников, цель — www.youtube.com:443.

Три регрессионных теста запуска проверяют пустую базу, выбранный профиль,
последующие изменения профиля и ограничение времени ожидания. При старте
слушатели профилей создаются до ожидания их `.future`, чтобы Riverpod 3
не приостанавливал поток. Ошибка инициализации отображается на русском,
заставка снимается в `finally`.

## Пакеты

- Android: сборка на Microsoft JDK 25.0.4.1, Gradle 9.1.0, AGP 9.0.1,
  Kotlin 2.3.21; JVM-цель приложения 17. APK включает armeabi-v7a,
  arm64-v8a и x86_64. Проверены архитектуры всех ELF-библиотек,
  присутствие ядра и SQLite во всех трёх вариантах и подпись apksigner.
- Android SHA-256 сертификата:
  `2030a90ce3dc8007010d614235b07a0c6c181b638a818b4c14c1e3c5d4a12225`.
  Совпадает с 4.1.20; обновление поверх предыдущей версии сохраняется.
- macOS: отдельные Apple Silicon и Intel ZIP. Упаковщик проверяет каждый
  Mach-O, удаляет вторую архитектуру только в копии для упаковки, заново
  подписывает вложения и проверяет `codesign --verify --deep --strict`.
- Windows: только Setup EXE x64. Упаковщик проверяет наличие SQLite,
  ядра, среды Flutter и VC++ runtime; PE-библиотеки и AOT-снимок x86-64.
  До работы с VM активируется временный файл подкачки 2–6 ГБ без изменения
  постоянных параметров Windows.

## Ограничения

macOS требует [локальный обход ошибки AOT Flutter #191575](FLUTTER-MIGRATION-3.47.7.md).
Основной установленный Flutter SDK не изменён. Обход сохранён в исходниках;
CI использует те же изменения в собственном SDK.

APK подписан прежним debug-сертификатом; macOS использует ad-hoc подпись
без Developer ID и нотариализации; Windows EXE не имеет Authenticode.
Подписанный установочный пакет iOS не выпускается без Apple Developer.

Эти проверки не подтверждают работу каждого публичного прокси, непрерывность
реального браузерного сеанса или воспроизведение YouTube через пользовательский
сервер. Тесты воспроизведения проверяют алгоритм подтверждения кадров и времени.
