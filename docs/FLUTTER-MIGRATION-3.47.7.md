# Переход на Flutter 3.47.7

Исходники ProxyYou 4.1.21 адаптированы к Flutter 3.47.7 stable и Dart 3.13.5.
Миграция сначала проверена без сборки приложений. После отдельного запроса
пользователя подготовлен выпуск 4.1.21 для Android, macOS и Windows.
Подписанный iOS-пакет требует учётной записи Apple Developer.

## Зависимости и совместимость

- Font Awesome 11 использует `FaIcon`; удалённые из Simple Icons фирменные
  символы облачных провайдеров заменены подходящими Material-значками.
  Флаги загружаются из опубликованного `circle_flags` 5.0.1 вместо Git-форка
  с несовместимым описанием генератора.
- Riverpod 3: обновлены семейства провайдеров, наблюдатели, `Ref`, чтение
  `AsyncValue` и обработка обёрнутых исключений. Автоматические повторы
  контейнера отключены: существующие явные повторы подключения сохранены.
  Подписки фонового ядра продолжают работать независимо от фокуса окна.
- Обновлены совместимые версии Freezed, Drift, Slang, JSON и Riverpod
  генераторов, flutter_gen, dart_mappable и ffigen. `build_runner` закреплён
  на совместимой ветке 2.16: переход на 2.17 требует несовместимого build 5.
- Drift использует нативные ресурсы sqlite3 3; устаревший плагин
  `sqlite3_flutter_libs` удалён из зависимостей и регистраторов платформ.
- Генерация переводов вынесена в `slang.yaml` и выполняется до build_runner.
  Это обеспечивает правильное разрешение типов Riverpod в чистом checkout.
- Новый `onReorderItem` уже передаёт скорректированный индекс; повторная
  коррекция удалена. Тесты проверяют перемещение вверх, вниз и сохранение
  порядка в файле правил.
- Android: Gradle 9.1.0 с проверкой SHA-256 архива, AGP 9.0.1, Kotlin
  2.3.21, Java 25. Обновлён flutter_displaymode до 0.7.0, использующий
  compileSdk проекта вместо устаревшего API 33. Минимальная версия Android — 7.0 (API 24), как требует SDK.
- `installed_apps` 2.2.1 заменяет старый Git-форк. Выбор приложений сохраняет
  системные и фоновые пакеты; ненужный просмотр содержимого каждого APK
  для определения технологии приложения отключён.
- Сохранены JVM-цели Java/Kotlin 17 для Android: JDK 25 используется для
  запуска сборки. Старый Sentry компилируется в режиме языка Kotlin 2.0;
  ресурсные идентификаторы настроены для оптимизации AGP 9.
- Windows CMake копирует нативные ресурсы Dart, включая `sqlite3.dll`.
  Упаковка проверяет наличие и архитектуру SQLite вместе с остальными DLL.
- Скрипты macOS/Android/Windows, Dockerfile и CI используют согласованную
  версию Flutter из `pubspec.yaml`.

## Воспроизведение проверок

### Обход ошибки AOT macOS в Flutter 3.47.7

Обычная сборка macOS воспроизводит ошибку компилятора
[Flutter #191575](https://github.com/flutter/flutter/issues/191575):
`Class with illegal cid, full-aot` для `_Rect` экспериментального оконного API.
Официальный stable 3.47.7 не содержит исправления. Для пакетов macOS
используется отдельная копия этого SDK с локальным обходом: пять FFI-структур
помечены `vm:entry-point`. Экспериментальный оконный режим не включается.
Это не официальный патч Flutter или перенос исправления Dart VM.

Скрипт проверяет точную ревизию SDK и исходный текст файла, отказывается
перезаписывать посторонние изменения и допускает повторный запуск:

```sh
python3 scripts/prepare-flutter-macos-sdk.py --sdk /path/to/private/flutter-3.47.7
export PATH=/path/to/private/flutter-3.47.7/bin:$PATH
```

Основной установленный SDK не изменён. CI применяет тот же обход к своему
изолированному SDK. После официального исправления этот скрипт нужно удалить.

```sh
flutter pub get
dart run slang
dart run build_runner clean
dart run build_runner build
bash scripts/generate-test-certificates.sh
flutter analyze --no-pub
flutter test --no-pub --concurrency=1
node --test test/playback/proof.test.cjs test/site/downloads.test.mjs
```

Два дополнительных нагрузочных теста включаются переменной
`PROXYYOU_SUBSCRIPTION_TEST_DIRECTORY`: в указанной папке нужны файлы
`subscription-load-test.json` и `subscription-all-load-test.json`.
Публичные конфигурации в репозиторий не добавляются.

## Проверки на macOS 15 октября 2026

- Чистая генерация: завершена, 934 результата; сгенерированные файлы
  не редактировались вручную.
- Анализ: без замечаний. Flutter: 242 теста прошли, без пропусков.
  JavaScript: 18 тестов прошли.
- В тесте с 50 000 конфигураций сортировка заняла 92 мс, обработка ссылок —
  37 мс; обработчик кадров интерфейса продолжал получать управление.
- Контрольные подписки пользователя: 33 728 конфигураций/20 МБ обработаны
  за 619 мс, 65 736 конфигураций/35 МБ — за 869 мс. Максимальный промежуток
  между контрольными сигналами интерфейса — 21 и 7 мс соответственно.
  Это результат конкретного запуска, не сравнительный замер ускорения.
- Через FFI с существующей arm64-библиотекой 4.1.20 проверены создание групп
  select/balance/lowest без запроса разрыва соединений и предел 20
  одновременных SOCKS-проверок с единственной целью www.youtube.com:443.
- Четыре теста значка macOS проверяют цвет при подключении, отсутствие
  зависимости от готовности пинга, последовательность обновлений и сброс
  значка после ошибки соединения.

Сборка и запуск Android, Intel macOS, Windows-приложения и подписанного iOS
этим набором проверок не заменяются. Работа реального VPN и воспроизведение
YouTube на пользовательском сервере в рамках миграции не проверяются.

## Проверки Windows 11 x64 под эмуляцией ARM64

- Flutter 3.47.7 / Dart 3.13.5: чистая генерация 934 результатов, анализ без
  замечаний, 236 тестов прошли, 6 пропущены (права POSIX и значок macOS).
- Исправлена коллизия MoveFileEx при одновременных сохранениях: только
  атомарная замена одного файла выполняется последовательно; валидация
  разных временных файлов остаётся параллельной.
- Существующая DLL 4.1.20 прошла FFI/gRPC-проверки групп и 20 работников.
- Перед каждым запуском Windows автоматически включается временный файл
  подкачки 2–6 ГБ. Постоянные настройки ОС не меняются.
