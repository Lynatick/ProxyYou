# ProxyYou 4.1.23

Исправления, проверенные в macOS Apple Silicon, включены в общий клиент
macOS Intel, Android / Android TV и Windows x64.

- Команды и состояние ядра отделены от потока списков и статистики на всех платформах.
- Скрытый экран продолжает читать ответы ядра и сохраняет только последний снимок.
  Проверка пинга больше не оставляет очередь необработанных конфигураций.
- Завершение выбора сервера после закрытия списка не обращается к удалённому состоянию.
- Главная следует выбранному пути `select` и показывает задержку выбранного сервера.
  В `balance` отображается последний сервер, успешно установивший соединение.
- Проверены переходы между конкретным сервером и `balance` / `lowest` в обе стороны.
  Штатные настройки сохраняют существующие TCP/UDP-соединения; потерянную сессию
  отказавшего сервера перенести на другой сервер невозможно.
- Вспомогательный виброотклик не задерживает управление подключением.
- Windows использует сетевую проверку YouTube и миниатюр. Видеоплеер, кнопка
  проверки воспроизведения и зависимость WebView2 удалены. На macOS и Android
  проверка воспроизведения с декодированными кадрами сохранена.

Выпуск: отдельные ZIP macOS arm64 и x86_64, APK Android с тремя ABI,
один EXE-установщик Windows x64. Сборки выполняются локально.
Android собирается с Java 25; перед работой в Windows активируется временный
файл подкачки. Ключи подписи остаются на локальной машине.
