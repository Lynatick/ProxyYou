# Проверка ProxyYou 4.1.20

Дата: 14 октября 2026 года.

- Flutter 3.38.5 / Dart 3.10.4: анализ без замечаний, 226 тестов прошли, 2 дополнительных теста публичных подписок пропущены.
- Индикатор изменений: SHA-256 до разворачивания/конвертации подписки; условный GET/304; одинаковое содержимое при новом ETag; сервер без валидаторов; отмена; сетевой отказ; смена URL; отсутствие автоматического применения; общий запрос при смене фокуса; исчезновение индикатора после обновления.
- Карточка конфигурации: имя/протокол без IP; режим balance/lowest выше имени только для выбранной группы, с защитой от совпадения имени обычного сервера.
- YouTube: generate_204 и отдельная загрузка JPEG-миниатюры; запрет HTML вместо JPEG, обычная проверка TLS, отсутствие DIRECT fallback. Успех запроса не выдаётся за подтверждение воспроизведения. Мониторинг серверов по-прежнему обращается только к generate_204, максимум 20 проверок.
- Нативный Go: проверка генератора select/balance/lowest и 8 интеграционных случаев переключения. Основные Lowest/Round-robin используют штатные параметры, дополнительные hashing/sticky — явно заданные retry/TTL. После смены сервера сохранённые TCP/UDP передают ещё по 100 сообщений; новые соединения идут через новый сервер. Полный отказ старого TCP-транспорта разрывает его поток.
- Собранные macOS arm64 dylib и Windows x64 DLL: smoke-проверка сгенерированных групп и фактические 20 одновременных проверок, единственная цель www.youtube.com:443, всё на локальных серверах. Никаких изменений системного прокси.
- Нативные ядра собраны из одних исходников для macOS arm64/x86_64, Android ARM/ARM64/x64, Windows x64. Патч и тесты включены в native-patches/connection-continuity.patch.
- JavaScript: 10 тестов доказательства воспроизведения и 8 тестов страницы загрузки прошли.

Ограничения: физический Mac Intel и Android TV для интерактивного испытания отсутствуют. Для старых подписок без исходного отпечатка первая проверка создаёт точку сравнения; ручное обновление сохраняет отпечаток применённой версии. Смена целой подписки и применение обновления могут требовать перезапуска ядра; исправление касается выбора серверов и режимов внутри работающего подключения.

Подписи тестовых сборок: Android — прежний Android Debug сертификат, macOS — ad hoc, Windows — без Authenticode. iOS-пакет не создаётся без Apple Developer подписи для VPN.
