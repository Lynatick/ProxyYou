# Сообщения об уязвимостях

Используйте вкладку Security → Report a vulnerability этого репозитория. Не публикуйте в Issues секреты, адреса частных подписок, ключи подписи или данные пользователей.

Поддерживается текущая версия ProxyYou. Установка пакетов через встроенный механизм обновления ещё не реализована; ссылки в исходниках настроены на этот репозиторий, проверка обновлений отключена.

Не используйте тестовые ключи Android для публичных релизов. В репозиторий не должны попадать ключи подписи приложений и манифеста обновления. Сертификаты localhost для тестов генерируются при запуске CI и не являются ключами выпуска.
